# Jawad Hojeij — Engineering Portfolio

A responsive English-language portfolio for the 3EA engineering programme at Toulouse INP–ENSEEIHT.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the root of the repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Your site will be published at `https://jjh313.github.io/jawad-portfolio/`.

## Personalise before publishing
- Add your CV PDFs in `assets/` using the filenames `CV_Jawad_Hojeij_EN.pdf` and `CV_Jawad_Hojeij_FR.pdf`.
- Update the LinkedIn URL and email in `index.html` if needed.
- Replace the Elevator Pitch placeholder with your video embed/link.
- Complete the mobility, RSE and role-model sections with verified information.
- Add only project reports/images you are allowed to share.

The page intentionally labels unfinished portfolio content as to-be-added / exploring rather than presenting it as completed.
